# FicBurrow

A personal library for saving stories and keeping reading notes across your browsers and devices.

- **Product page:** https://brownie-studio-dev.github.io/ficburrow/
- **Downloads:** [GitHub Releases](https://github.com/Brownie-Studio-dev/ficburrow/releases)
- **Feedback and feature requests:** [Issues](https://github.com/Brownie-Studio-dev/ficburrow/issues)
- **Privacy policy:** https://brownie-studio-dev.github.io/privacy.html
- **Browser extension stores:** links will be added when listings are available.
- **iPhone:** a native Safari extension is planned for the App Store. The userscript remains available as an alternative.

This repository is the public product, download, and feedback hub. It does not contain the application source code. Development continues in a separate private repository.
